Política de Privacidade

OLI Health Hub — Versão 1.0 · Maio 2026

1. Quem somos

O OLI Health Hub é uma plataforma de gestão para profissionais de saúde, operada pela OLI Health Hub Ltda., localizada na Av. Paulista, São Paulo – SP. Responsável pelo tratamento de dados: Guilherme Pasquetti (guilherme@olihealthhub.com.br).

2. Dados que coletamos

  • Nome completo, e-mail e CRM/registro profissional
  • Especialidade médica e duração padrão de consulta
  • Dados de reservas de sala (horários, duração, sala utilizada)
  • Dados de pacientes cadastrados com consentimento explícito (nome, telefone, diagnóstico — armazenados criptografados)
  • Logs de uso para faturamento por minutagem
  • Dados de autenticação (e-mail, hash de senha — nunca a senha em texto)

3. Dados que NÃO coletamos

  • CPF em texto puro — armazenamos apenas hash SHA-256 + últimos 3 dígitos
  • Dados de cartão de crédito ou conta bancária
  • Conteúdo de consultas médicas ou prontuários (apenas referência de ID quando integrado ao Communicare)
  • Localização GPS

4. Base legal (LGPD)

O tratamento de dados se baseia em:

  • Execução de contrato (Art. 7º, V) — para gerenciar reservas e faturamento
  • Consentimento explícito (Art. 7º, I) — para dados de pacientes cadastrados
  • Legítimo interesse (Art. 7º, IX) — para segurança e prevenção de fraudes

Dados de saúde dos pacientes são tratados como dados sensíveis (Art. 11) com base em consentimento específico registrado com timestamp.

5. Como usamos os dados

  • Gerenciar reservas de salas e calcular cobrança por minutagem
  • Enviar notificações de sessão, buffer e alertas de conta
  • Gerar relatórios de uso para o profissional
  • Cumprir obrigações legais e tributárias
  • Melhorar a plataforma com base em dados agregados e anonimizados

6. Compartilhamento

Não vendemos dados pessoais. Compartilhamos apenas com:

  • Supabase (infraestrutura de banco de dados — servidores sa-east-1, Brasil)
  • Asaas (processamento de pagamentos — PCI DSS)
  • Communicare (prontuário eletrônico — apenas quando autorizado pelo médico)
  • Autoridades competentes, quando exigido por lei

7. Segurança

  • Dados em trânsito: TLS 1.3
  • Dados em repouso: criptografia AES-256 (Supabase + expo-secure-store)
  • Autenticação: MFA TOTP disponível, app lock biométrico
  • Audit log imutável de acesso a dados de saúde
  • Rate limiting: máx. 5 tentativas de login por 15 minutos

8. Seus direitos (LGPD Art. 18)

Você pode exercer os seguintes direitos pelo app (Perfil → Privacidade) ou por e-mail:

  • Confirmação e acesso — ver todos os dados que temos sobre você
  • Portabilidade — exportar seus dados em formato JSON
  • Exclusão — apagar sua conta e todos os dados pessoais
  • Correção — editar dados incorretos diretamente no app
  • Revogação de consentimento — remover consentimento dado a qualquer momento

9. Retenção de dados

Dados pessoais são mantidos enquanto a conta estiver ativa. Após exclusão da conta, os dados são removidos em até 15 dias úteis. Logs de auditoria são mantidos por 5 anos para fins de conformidade regulatória.

10. Menores de idade

Esta plataforma é destinada exclusivamente a profissionais de saúde habilitados. Não coletamos dados de menores de 18 anos.

11. Alterações nesta política

Alterações relevantes serão notificadas via push notification e e-mail com antecedência mínima de 15 dias. O uso continuado após a notificação implica aceite.

12. Contato e DPO

Para exercer seus direitos ou tirar dúvidas: privacidade@olihealthhub.com.br
